# Predictive Analytics Using Historical Data

## Project Overview
This project analyzes historical sales data and uses Machine Learning to predict future sales trends. It provides an interactive dashboard built using Python and Streamlit.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Random Forest Regressor
- Plotly
- Streamlit

## Key Features
- Historical sales data analysis
- Data cleaning and preprocessing
- Monthly sales trend visualization
- Machine Learning model training
- Model evaluation using MAE, RMSE, and R² Score
- Actual vs Predicted sales comparison
- Future 12-month sales forecasting
- Downloadable forecast results

## Dataset
Store Item Demand Forecasting Challenge dataset from Kaggle.

Download: https://www.kaggle.com/competitions/demand-forecasting-kernels-only/data

Download and extract `train.csv` into the project folder before running the application.

## How to Run

1. Install the required libraries:
   `pip install -r requirements.txt`

2. Run the application:
   `streamlit run app.py`

3. Open the local URL displayed in the terminal.
